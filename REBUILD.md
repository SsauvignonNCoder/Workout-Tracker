# Как пересобрать приложение после редизайна

Инструкция для обновления дизайна в репозитории и пересборки проекта.
Изменены всего **два файла**: `src/App.jsx` и `index.html`. Логика и зависимости не менялись.

---

## Что понадобится

- Установленный **Node.js 18+** (проверить: `node -v`)
- Терминал, открытый в папке проекта `workout-tracker-web`

---

## Шаг 1. Заменить файлы

Скопируй из этого редизайна поверх старых:

```
src/App.jsx   →  заменить
index.html    →  заменить
```

> Новые шрифты (Space Grotesk, Manrope, JetBrains Mono) подгружаются из Google Fonts
> прямо в `index.html` — ставить ничего дополнительно не нужно.

---

## Шаг 2. Установить зависимости (только если ещё не стоят)

```bash
npm install
```

Делается один раз. Если папка `node_modules` уже есть — пропусти этот шаг.

---

## Шаг 3. Проверить локально (по желанию)

```bash
npm run dev
```

Откроется адрес вида `http://localhost:5173` — посмотри, что дизайн встал и приложение работает.
Останови сервер: `Ctrl + C`.

---

## Шаг 4. Собрать продакшен-версию

```bash
npm run build
```

Готовая сборка появится в папке **`dist/`**. Это и есть файлы для деплоя.

Посмотреть собранную версию локально:

```bash
npm run preview
```

---

## Шпаргалка по командам

| Команда           | Что делает                                  |
|-------------------|---------------------------------------------|
| `npm install`     | Ставит зависимости (один раз)               |
| `npm run dev`     | Запуск в режиме разработки (живой просмотр)  |
| `npm run build`   | Сборка продакшен-версии в `dist/`           |
| `npm run preview` | Локальный просмотр собранной версии         |

---

## Если что-то пошло не так

- **`command not found: npm`** — не установлен Node.js. Поставь с https://nodejs.org (LTS-версия).
- **Ошибка про `lucide-react` / иконку** — выполни `npm install`, затем снова `npm run build`.
- **Старый дизайн после сборки** — почисти кэш браузера (Ctrl/Cmd + Shift + R) или удали папки `dist` и `node_modules/.vite`, потом пересобери.
- **Любая другая ошибка сборки** — скопируй текст ошибки из терминала и пришли мне, помогу разобраться.
