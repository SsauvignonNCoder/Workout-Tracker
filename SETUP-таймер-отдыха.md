# Таймер отдыха + звук в наушники при выключенном экране

Что входит в этот архив:

- `src/tabs/GuidedWorkout.jsx` — обновлённый пошаговый режим: таймер отдыха теперь считает **по реальному времени** (не «зависает», когда экран гаснет), пересчитывается при возврате в приложение, и при старте отдыха планирует бот-уведомление, а при пропуске/закрытии — отменяет его.
- `src/tabs/workoutTabHelpers.jsx`, `src/tabs/WorkoutTab.jsx` — из прошлых правок (болгарские сплит-приседы, секторное кардио, кнопка «Начать тренировку»). Если ещё не залил их — залей вместе с этим.
- `api/rest-schedule.js`, `api/rest-fire.js`, `api/rest-cancel.js` — новые серверные функции (Vercel), которые присылают сообщение бота ровно в конце отдыха.
- `rest_done.mp3` — короткий звук-джингл (1.75 с) для чата с ботом. Если хочешь именно голос — см. ниже.

---

## Почему так, коротко

Когда экран телефона гаснет, JavaScript внутри Telegram Mini App замораживается — таймер внутри страницы не может подать сигнал. Поэтому звук приходит **снаружи**: бот присылает сообщение «Отдых окончен» точно через 2 минуты, а телефон проигрывает его звук в наушники даже с выключенным экраном.

Точность обеспечивает планировщик **Upstash QStash** (секунда-в-секунду, без задержек «ежеминутного крона»). Если ты пропускаешь отдых кнопкой-наушником раньше времени — уведомление отменяется, лишнего сигнала не будет.

---

## Настройка (разово)

### 1. Аккаунт Upstash QStash (бесплатно)

1. Зарегистрируйся на https://upstash.com → раздел **QStash**.
2. Скопируй **QSTASH_TOKEN** (на странице QStash → Details/Request Builder, поле Token).
   Бесплатного лимита (сотни сообщений в день) хватает с запасом.

### 2. Переменные окружения в Vercel (Production И Preview)

Добавь в Vercel → Project → Settings → Environment Variables:

- `QSTASH_TOKEN` — токен из шага 1.
- `REST_ALERT_SECRET` — любая случайная строка (например, 32 символа). Используется только на сервере, чтобы никто не мог подделать вызов отправки. Придумай сам, никуда больше вставлять не нужно.
- `TELEGRAM_BOT_TOKEN` — уже настроен, ничего не меняй.

После добавления — **Redeploy** (или просто залей файлы, Vercel пересоберёт).

> Домен для обратного вызова QStash подставляется автоматически из адреса запроса — настраивать не нужно.

### 3. Звук на чат с ботом (чтобы «пело» только от бота)

iOS-фича «Объявление уведомлений» читает **все** сообщения приложения — не подходит. Вместо неё ставим **свой звук именно на чат с ботом**, тогда сигнал будет только от него, а личные чаты звучат как обычно.

1. Пришли файл `rest_done.mp3` себе в Telegram (например, в «Избранное»).
2. Нажми на него → меню (⋮ / долгий тап) → **«Добавить в звуки уведомлений»** (Add to Notification Sounds).
3. Открой чат с ботом → имя бота сверху → **«Уведомления»** (Customize / Sound) → выбери загруженный звук `rest_done`.

Готово: теперь в конце отдыха телефон проиграет этот звук в наушники даже с выключенным экраном.

## Если хочешь именно ГОЛОС «Отдых окончен» (а не джингл)

Живую русскую речь я в своём окружении сгенерировать не смог (нет доступа к TTS), но ты сделаешь клип за минуту:

**Способ А — iPhone, приложение «Команды» (Shortcuts):**
1. Создай команду → действие **«Сделать устную аудиозапись»** (Make Spoken Audio from Text), текст: `Отдых окончен, следующий подход`.
2. Добавь действие **«Сохранить в Файлы»** (или «Поделиться»).
3. Запусти команду → получишь аудиофайл ≤5 сек.
4. Пришли его в Telegram и поставь звуком на чат с ботом (как в разделе 3 выше).

**Способ Б:** запиши голосовое своим голосом «Отдых окончен» (2 сек) и так же поставь звуком.

Ограничение Telegram для кастомных звуков — до 5 секунд, так что коротко.

## Как это работает в приложении (без изменений в привычном сценарии)

- Отдых стартует кнопкой «Подход выполнен · отдых 2 мин» — как и раньше.
- Таймер идёт по реальному времени: свернул/погасил экран → вернулся → он показывает правильное оставшееся время или сразу «Отдых окончен».
- С выключенным экраном звук даёт бот (если настроен QStash). Без QStash приложение всё равно работает — просто без звука в фоне (таймер и сигнал при возврате в приложение остаются).
- Кнопка-наушник (пропустить) и закрытие тренировки отменяют запланированное бот-уведомление.
